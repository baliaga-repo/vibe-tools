# Skill: Grill With Docs

Align project terminology, domain boundaries, and architectural decisions through an interactive probing session that documents outcomes directly into repo docs.

## Workflow
1. **Domain Boundary Analysis**: Identify key entities, naming ambiguities, and data contracts across the target feature.
2. **Interactive Challenge**: Question conflicting definitions or leaky abstractions using structured options.
3. **Glossary Update**: Record approved domain terms into `docs/GLOSSARY.md` or `.agents/GLOSSARY.md`.
4. **Architectural Decision Record (ADR)**: Generate or update an ADR in `docs/adr/` documenting:
   - Context and problem statement.
   - Alternatives considered and trade-offs.
   - Final decision and consequences.
