# Konversi ke Spesifikasi Teknis (/to-spec)

1. Baca panduan skill `.agents/skills/to-spec/SKILL.md` (atau `~/.gemini/config/skills/to-spec/SKILL.md` jika tersedia).
2. Susun spesifikasi teknis yang padat dan terstruktur di dalam `docs/specs/<nama-fitur>.md` menggunakan Bahasa Indonesia.
3. Sertakan: Ringkasan & Tujuan, Kontrak Antarmuka / Struktur Data, Alur Kerja (Mermaid), Matriks Error & Guardrails, serta Kriteria Penerimaan.
4. **DILARANG menyentuh file `.py`** pada tahap ini. Minta persetujuan pengguna setelah dokumen spesifikasi selesai ditulis.
